# Task Vault

Monorepo con la documentación y proyectos desarrollados durante el ciclo de trabajo.

## Proyectos

### agrovelas/
Sistema de gestión ganadera (Google Apps Script + Google Sheets). Control de animales, sanidad, esquila, IoT, genética y contabilidad para operaciones ganaderas andinas. Corre completamente sobre infraestructura gratuita de Google.

### essalud/
Documentación del sistema de gestión de trámites para EsSalud (Perú). Incluye especificaciones para versión Laravel 11 con chatbot RAG, OCR, y portal ciudadano. Versiones: `v1.0-laravel/`, `v1.0 empresarial/` (Flutter), `v1.0/` (spec original).

### wasiyuq/
Plataforma de adopción de mascotas para Cusco, Perú. Laravel + Vue 3 + Inertia.js. Gestión multi-tenant de refugios, postulaciones, seguimiento post-adopción y generación automática de actas legales.
